# 池袋ローグ ～単位を集めて卒業せよ～

池袋の大学に入学した大学生が、4年間を生き延びて **124単位** を集め、卒業を目指すドット絵ローグライクです。

- ブラウザだけで動く（HTML / CSS / JavaScript のみ、ビルド不要）
- ドット絵はすべてコード内で描画（画像ファイルなし）
- 効果音も WebAudio で生成（音声ファイルなし）
- サーバー・データベース不要 → **GitHub Pages で運用費0円**
- スマホ（タッチ操作）・PC（キーボード）両対応

## ゲーム内容

| 学年 | エリア | 主な敵 | ボス |
| --- | --- | --- | --- |
| 1年 | 池袋駅 地下迷宮 | 鳩・小テスト・寝坊の悪魔・キャッチ | 必修英語の期末試験 |
| 2年 | サンシャイン60通り | カラス・酔っ払い・レポート課題 | 統計学の鬼教授 |
| 3年 | 西口 夜の繁華街 | 終電・中間試験・インターン選考 | 集団面接官 |
| 4年 | キャンパス 研究室棟 | 締切・徹夜の悪魔・圧迫面接官・赤ペン教授 | 卒業論文 |

- 各学年は「前期 → 後期 → 期末試験（ボス）」の3フロア、全12フロア
- フロアは毎回ランダム生成。体力0で **退学（ゲームオーバー）**
- 単位は試験系の敵やボスを倒す、出席票を拾うことで取得
- 満腹度システム（池袋ラーメンで満腹！）、装備（筆記用具・服）、コンビニでの売買、いけふくろう像
- 学年末には成績発表と、春休みの過ごし方（バイト・合宿・図書館・帰省）の選択
- エンディングは単位数で分岐（首席卒業 / 卒業 / 留年）
- 進行はフロアごとにブラウザ（localStorage）へ自動保存

## ローカルで遊ぶ

`index.html` をブラウザで開くだけで遊べます。
（もしくは `python3 -m http.server` を実行して http://localhost:8000 を開く）

## 無料で公開する（GitHub Pages）

1. このリポジトリを **Public** にする（Private の場合、GitHub Pages は有料プランが必要）
2. GitHub のリポジトリ画面 → **Settings → Pages** → Source を **GitHub Actions** にする
3. `main` ブランチに push すると `.github/workflows/pages.yml` が自動で公開
4. `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べる

Cloudflare Pages / Netlify などの無料静的ホスティングでも、ファイルをそのまま置くだけで動きます。

## ファイル構成

```
index.html      画面レイアウト
style.css       見た目（スマホ対応）
js/sprites.js   ドット絵・タイルの定義と描画
js/game.js      ゲーム本体（マップ生成・戦闘・AI・UI・セーブ）
```

フォントは Google Fonts の「DotGothic16」（無料）を読み込んでいます。
